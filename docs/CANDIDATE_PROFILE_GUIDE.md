# Candidate Profile Recommendations

The example profile is tuned for senior Snowflake/data-architecture work without storing a name or contact details.

Before production use, verify:
- Employment structure: direct employers versus consulting client assignments.
- Certification wording: list only completed credentials as certified; label scheduled or in-progress exams accurately.
- Every scale/cost claim has defensible evidence.
- Preferred titles, locations, compensation floor, travel, contract preference, and sponsorship response.
- Recent evidence for Snowflake, dbt, Airflow, AWS, architecture leadership, governance, and performance optimization.

Recommended resume improvements:
- Add measurable platform scale, team size, SLA, volume, latency, and savings to recent roles.
- Keep a two-page ATS version and a longer evidence inventory used only for tailoring.
- Explain the relationship between consulting employer and client engagements consistently.
- Avoid keyword insertion unless a verified claim supports it.
