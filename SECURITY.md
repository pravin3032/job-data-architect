# Security Policy

Do not commit resumes, addresses, phone numbers, email addresses, credentials, tokens, demographic answers, or browser profiles. Store them in ignored local files or a managed secret/private document store.

Report vulnerabilities privately through GitHub Security Advisories. Do not open a public issue containing personal data or credentials.

Automation must not bypass CAPTCHA, MFA, rate limits, access controls, or employer attestations. Public ATS ingestion must respect source terms and reasonable request rates.
